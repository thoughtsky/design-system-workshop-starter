# Figma MCP Design System Workshop

Minimal starter for a live workshop about generating design system components from Figma using a coding agent and Figma MCP.

## Install

```sh
npm install
```

## Development

```sh
npm run dev
```

## Storybook

```sh
npm run storybook
```

## Production Builds

```sh
npm run build
npm run build-storybook
```

Components will be generated from scratch during the workshop. This repo intentionally starts without UI components.
